# **App Name**: Dr. Dry Wash Online

## Core Features:

- Service Listing: Display available laundry services (wash & fold, dry cleaning, ironing, etc.) with pricing, mirroring the services offered on Laundry Xpress website. Update the copy with the Dr. Dry Wash Brand and voice.
- Order Placement: Allow users to select services, specify quantities, and schedule pickup and delivery times, following the workflow of Laundry Xpress.
- Location Selection: Enable users to input their location (address) to determine service availability and calculate delivery fees.
- Payment Gateway Integration: Integrate with a secure payment gateway (e.g., Stripe) to process online payments for laundry orders.
- Order Tracking: Provide users with real-time updates on their order status (e.g., 'Order Placed', 'In Transit', 'Cleaning', 'Ready for Delivery', 'Delivered').
- Promotional Banner Generation: Utilize a generative AI tool to create promotional banners. Input parameters can include the type of laundry service, discount percentage, and target audience, resulting in a unique visual for marketing campaigns.
- Contact Form: A contact form where users can send feedback. Or request customer service. 

## Style Guidelines:

- Primary color: A clean, vibrant blue (#29ABE2) to evoke feelings of cleanliness, freshness, and reliability, aligning with the laundry service concept.
- Background color: A very light blue (#F0F8FF), almost white, to create a sense of hygiene and allow the vibrant blue to stand out.
- Accent color: A complementary orange (#FF8C00), offering contrast to the primary blue, suitable for CTAs, special offers, and highlights, to create interest.
- Body and headline font: 'PT Sans', a humanist sans-serif, offering a balance of modernity and approachability for readability.
- Use flat, modern icons that clearly represent each laundry service and step in the order process.
- Maintain a clean, organized layout with clear sections for services, ordering, tracking, and contact information.
- Use subtle animations (e.g., fade-in effects, progress bar updates) to enhance the user experience and provide feedback on actions.
